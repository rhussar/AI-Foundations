Homework 1: Problem 2 → Problem 8 Flow

From raw document pack to reconciled transactions, to January income statement, to final HTML report

Input
Document pack
PDF receipts, bank statement, credit card statement, emails, notes, and manifest
→
Goal
Turn raw records into a January income statement
Extract, reconcile, decide what belongs in the business, and summarize it
Problem 2
Extraction
read_receipts.py
Reads receipt PDFs and uses the LLM to pull out purchase details.
LLM call
→
Output
receipts.json
Vendor, Date, Description, Amount_USD, Category, source_file, fields_not_found
Problem 3
Extraction
read_bank.py
Reads the bank statement and classifies each row as business or personal.
LLM call
→
Output
bank_transactions.json
Date, Description, Amount_USD, Classification, Direction, Accounting label, Expense type
Problem 4
Extraction
read_card.py
Reads the credit card statement and separates business from personal spending.
LLM call
→
Output
credit_card_transactions.json
Date, Merchant, Amount_USD, Classification, Expense category
Problem 5
Reconciliation
reconcile.py
Combines the earlier JSON files and relevant documents to resolve duplicates, split decisions, and included/excluded items.
LLM call
→
Output
reconciliation_log.json
ID, sources, amounts_seen, included_income_statement, amounts_used_income_statement, resolution
Problem 6
Judgment calls
judgment calls from the reconciliation log
Selects the three hardest decisions and records the evidence and confidence level.
LLM call
→
Output
judgment_calls.json
transaction ID, included_income_statement, amount_used, evidence, confidence
Problem 7
Financial summary
income_statement.py
Uses the reconciliation log to roll all included rows into revenue and expense totals for January 2026.
→
Output
income_statement_Jan_2026.json
period, revenue_USD, expense_lines, Total_expenses_USD, net_income_USD
Problem 8
Reporting
report.py
Reads the JSON outputs and assembles the human-readable one-page summary.
→
Output
income_statement.html
Final January statement, excluded rows, and judgment calls
In plain English: the project began by turning every source document into organized transaction data, then reconciled overlap and personal-vs-business decisions, then built the January business summary, and finally produced a clean HTML presentation for human review.
